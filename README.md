## 🚀 Projects

🎮 **[GameStack](https://github.com/voltek/GameStack)** · *in progress*
A game backlog and discovery app built on the IGDB API, developed entirely with AI agents (mainly Claude Code).
The agent works inside a harness I designed and maintain: a `CLAUDE.md` with tiered rules, Skills for each recurring
task, ADRs that name what enforces them, a drift log, and a CI gate with branch protection.
Anything that needs judgment, like UX or scope, stops for my approval. The agent proposes, I decide.

📝 **[ModernNotes](https://github.com/voltek/ModernNotes)** · *completed*
An offline-first notes app with Clean Architecture, Room, DataStore and Hilt.
I wrote every line by hand. AI was used only to review the code, never to write it.

Two projects, two opposite ways of working with AI, both public and open to inspection.
